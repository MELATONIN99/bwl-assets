ONSOOM Publisher 개인정보처리방침

시행일: 2026-09-10

ONSOOM Publisher(이하 "본 도구")는 온숨 뷰티 웰니스 라운지(부산 해운대구 세실로27번길 13 선린빌딩 8층 801호)가 자사 소셜 미디어 계정(YouTube, TikTok 등)에 자체 제작 영상을 게시하기 위해 내부적으로 운영하는 소프트웨어입니다. 본 도구는 일반 대중에게 제공되지 않으며, 온숨이 소유·운영하는 계정에만 연결됩니다.

1. 수집하는 정보

본 도구는 계정 소유자가 OAuth 인증을 통해 명시적으로 허용한 범위 내에서만 다음 정보에 접근합니다: 채널/계정 식별자, 게시된 영상의 제목·설명·공개 상태. 시청자, 제3자, 팔로워의 개인정보는 수집하지 않습니다.

2. 이용 목적

수집한 정보는 오직 (1) 온숨 소유 계정에 영상을 업로드하고, (2) 업로드 결과(게시 여부, 영상 ID)를 확인하며, (3) 중복 게시를 방지하기 위해서만 사용됩니다.

3. 보관 및 보안

액세스 토큰과 게시 기록은 온숨이 관리하는 로컬 컴퓨터의 암호화된 저장소에만 보관되며, 외부 서버로 전송하거나 제3자와 공유하지 않습니다. 계정 소유자는 언제든지 각 플랫폼의 계정 설정에서 본 도구의 접근 권한을 철회할 수 있으며, 철회 시 저장된 토큰은 즉시 삭제됩니다.

4. Google API 서비스 이용자 데이터 정책

본 도구의 Google API 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 준수합니다. YouTube API 서비스를 이용하며, 이용자는 YouTube 서비스 약관 및 Google 개인정보처리방침의 적용을 받습니다.

ONSOOM Publisher Privacy Policy (English)

Effective: 2026-09-10. ONSOOM Publisher is an internal tool operated by ONSOOM Beauty Wellness Lounge (Busan, Korea) to upload its own videos to social media accounts it owns (YouTube, TikTok). It is not offered to the public. It accesses only what the account owner authorizes via OAuth: account/channel identifiers and the title, description and privacy status of videos it uploads. No data about viewers, followers or third parties is collected. Tokens and publishing logs are stored only on a local computer managed by ONSOOM and are never transmitted to or shared with third parties. Access can be revoked at any time from the platform's account settings; stored tokens are then deleted. Use of Google APIs complies with the Google API Services User Data Policy; use of YouTube API Services is subject to the YouTube Terms of Service and Google Privacy Policy.
